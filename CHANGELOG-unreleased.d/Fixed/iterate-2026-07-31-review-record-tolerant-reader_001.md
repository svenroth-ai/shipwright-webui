Mission Review no longer summarises a run as if the passes it cannot see do not exist. When a run records review passes somewhere this version does not read - true of every run today, because the spec-compliance gate is written to a place the Command Center never looked - the summary now says so instead of quietly leaving them out of its counts. Measured on a real run: 19 findings across 5 answered passes had been summarised as 14 across 3.

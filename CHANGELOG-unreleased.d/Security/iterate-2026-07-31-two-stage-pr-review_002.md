The `skip-pr-review` label no longer waives review of a change to the checks themselves. The tier decision now runs from default-branch code over GitHub API data - not from the pull request's own copy of the workflow - and classifies CI workflows, git hooks, the vendored reviewer, and the security-suppression channels (`.trivyignore.yaml`, `shipwright_accepted_risks.yaml`, `.semgrepignore`, `.claude/settings.json`, the bloat baseline) as always-review.

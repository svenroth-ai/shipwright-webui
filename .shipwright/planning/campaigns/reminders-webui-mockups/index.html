Reminders in the WebUI - mockups (W0)

Six static screens plus the open questions. Nothing here is built. Open each file in a browser; all data is invented. Please look, then say "go" (or what to change) in chat. W1-W3 do not start before that.

  1. The alert - three placements side by side, with a recommendation
  2. The due list - reminders and parked triage items, Done and Snooze
  3. Create a reminder - incl. "secret refused"
  4. Settings - mail on/off, recipient, SMTP, test mail, check interval
  5. The mail - as the recipient sees it
  6. Error states
  7. Open questions with recommendations
Rule used everywhere: all texts are untrusted and shown escaped as plain text; the WebUI never writes the reminder file, it only calls reminder_cli.py.

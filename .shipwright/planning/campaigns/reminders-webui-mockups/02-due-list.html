The Inbox with the entries opened. Cards are solid now, so they are readable. The first card is a reminder that was snoozed and came back today, with its Snooze menu open. What each button does:

  • Start task (only when the reminder has a command): creates a task card in that project, like Fix now in Triage. You press Launch yourself.
  • Done: marks the reminder done and removes it from the Inbox. Snooze: hides it until the day you pick (date picker, Tomorrow, Next week).
  • Parked triage items: only Open in Triage; they are acted on there.
  • The command text itself is not clickable. It is shown so you can see what Start task will run.

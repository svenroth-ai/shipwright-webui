Decisions and what is still open

Decided (your answers of 2026-11-22)

  • Alert: Reminders live in the Inbox. No banner, no bell, no extra page. The alert is the Inbox count plus the mail.
  • Mail: Yes, but off by default.
  • Mail format: Chosen in Settings: one mail per item, a daily summary, or both.
  • Parked triage items: One mail only (when the park expires), no repeats.
  • Create form: Yes, in a New-Task-style dialog; Why visible, the rest under More options; no command for hand-made reminders.
  • Projects: All registered projects.
  • Check interval: Hourly, plus once at server start.
  • Mail password: In .env.local in the WebUI's central user folder, outside every repo.
  • Snooze: Date picker plus Tomorrow / Next week.
  • Start task: Works like Fix now in Triage (creates a task card, you press Launch); the name stays.
  • Create dialog project: With All projects on the board you pick the project, like in New Task.
  • Daily summary time: Set in Settings (time, and whether to send when nothing is due).
  • Done on a parked triage item: Not offered; the entry links to Triage.

Still open (two, each with a recommendation)

  1. Reminders have a day only, no time of day. Is that enough? The reminder tool stores a day (YYYY-MM-DD). A time would be a change in Shipwright itself (store format and a contract version bump), which is outside this campaign. The server checks hourly anyway, so a time could only ever be accurate to the hour. Recommendation: Day only for now. If you want times, we do that as its own small Shipwright change first, then show it here.
  2. Start task when the command is a resume of an existing session You said: do it like Fix now. A command that continues an earlier session may need different handling than a fresh task. Recommendation: Build it exactly like Fix now. We check at W1 what the stored commands look like and raise it only if a resume command shows up.
